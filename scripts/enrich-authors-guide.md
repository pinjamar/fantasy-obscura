# Author Enrichment Guide

An author page is **indexable** only when it has `writing_style` filled in. Pages without it are noindexed and excluded from the sitemap. This guide covers how to enrich author pages so they qualify.

---

## What "Enriched" Means

The authors table has three editorial fields generated by this pipeline:

| Field | What it is | Required for indexing |
|---|---|---|
| `writing_style` | 2–3 sentences on prose, pacing, atmosphere | ✅ Yes |
| `best_starting_point` | Which book to read first and why | ✅ Yes (generated together) |
| `bio` | 2–3 sentence factual biography | No — filled only if missing or too short |

A page is noindexed if `writing_style` is null, blank, or under 80 characters.

### Example (Joe Abercrombie)

**writing_style:**
> Abercrombie's prose is a masterclass in grim realism, delivering sharp, cynical wit alongside brutal, visceral action. His stories are steeped in a pervasive atmosphere of moral ambiguity and political maneuvering, keeping readers glued to the page with dynamic pacing and characters who feel painfully, wonderfully human in their flaws. The world he crafts feels lived-in and scarred, a bleak canvas for human ambition and suffering.

**best_starting_point:**
> For an authentic taste of Abercrombie's grimdark genius, begin with *The Blade Itself*, the first book in *The First Law* series. This novel introduces his most iconic morally grey characters and the brutal, cynical world they inhabit, perfectly showcasing his sharp dialogue and visceral action. It's ideal for readers craving character-driven, unflinchingly realistic fantasy with a dark sense of humor.

## The Script

```
scripts/generate-author-bio.mjs
```

Uses **Gemini 2.5 Pro**. Feeds the author's name, top-rated books, subgenres, and tropes into a prompt and writes `writing_style` + `best_starting_point` (and `bio` if missing).

Requires `GEMINI_API_KEY` in `.env`.

---

## Commands

```bash
# Dry run — preview output without writing to DB
node scripts/generate-author-bio.mjs --dry-run

# Run on all authors with 5+ books missing writing_style
node scripts/generate-author-bio.mjs

# Run on a specific author
node scripts/generate-author-bio.mjs --slug joe-abercrombie

# Limit to N authors (useful for batching)
node scripts/generate-author-bio.mjs --limit 20

# Lower threshold (default is 5 books)
node scripts/generate-author-bio.mjs --threshold 3

# Overwrite existing enrichment (re-generate everything)
node scripts/generate-author-bio.mjs --all

# Combine flags
node scripts/generate-author-bio.mjs --limit 50 --dry-run
```

## How Many Are Left

```js
// Run to check current state
node --input-type=module << 'EOF'
import { createClient } from '@supabase/supabase-js';
import { readFileSync } from 'fs';
const env = Object.fromEntries(
  readFileSync('.env','utf8').split('\n')
    .filter(l => l.includes('=') && !l.startsWith('#'))
    .map(l => [l.split('=')[0], l.split('=').slice(1).join('=')])
);
const sb = createClient(env.PUBLIC_SUPABASE_URL?.trim(), env.SUPABASE_SERVICE_ROLE_KEY?.trim());
const { data: enriched } = await sb.from('authors').select('slug', { count: 'exact' })
  .gte('book_count', 3).not('slug', 'is', null).not('writing_style', 'is', null).not('best_starting_point', 'is', null);
const { data: plain } = await sb.from('authors').select('slug', { count: 'exact' })
  .gte('book_count', 3).not('slug', 'is', null).is('writing_style', null);
console.log(`Enriched (indexable): ${enriched?.length}`);
console.log(`Plain (noindexed, can be enriched): ${plain?.length}`);
EOF
```

## Manual Enrichment

For high-priority authors where you want to write the copy yourself, update directly:

```js
node --input-type=module << 'EOF'
import { createClient } from '@supabase/supabase-js';
import { readFileSync } from 'fs';
const env = Object.fromEntries(
  readFileSync('.env','utf8').split('\n')
    .filter(l => l.includes('=') && !l.startsWith('#'))
    .map(l => [l.split('=')[0], l.split('=').slice(1).join('=')])
);
const sb = createClient(env.PUBLIC_SUPABASE_URL?.trim(), env.SUPABASE_SERVICE_ROLE_KEY?.trim());
await sb.from('authors').update({
  writing_style: 'Your 2-3 sentence writing style description here.',
  best_starting_point: 'Your 2-3 sentence starting point recommendation here.',
}).eq('slug', 'author-slug-here');
console.log('done');
EOF
```

## Quality Rules

- **writing_style** must describe the *reading experience* — rhythm, atmosphere, emotional register. Not "vivid world-building" — say what specifically makes THEIR world-building distinctive.
- **best_starting_point** must name a specific book and say why it's the entry point. If it's a series, say so.
- **bio** should be factual and neutral — who they are, what they write, what they're known for. Not promotional.
- Avoid starting `writing_style` with the author's name — lead with the observation.
- Minimum ~80 characters per field or the page stays noindexed.

## Other Author Fields

These are populated by other scripts but worth knowing:

| Field | Script | Notes |
|---|---|---|
| `photo_url` | `backfill-author-photos.mjs` | Open Library author photo |
